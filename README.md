# Chyke Don Limited – Industrial Chemical Website

Modern multi-page website for **Chyke Don Limited**, an industrial chemical wholesaler, importer and exporter based in Lagos, Nigeria.

## Features
- Product catalog with search, filters, categories and pagination
- Request Quote (RFQ) form
- Import & Export page
- About Us & Contact pages
- Admin price manager
- Responsive design + sticky ticker + floating contact dock (Call / Email / WhatsApp)
- ~100 chemical products with images

## How to use
1. Open `index.html` in a browser (or serve the folder with any static server).
2. All pages share the same design system in `src/styles.css` and logic in `src/script.js`.
3. Product data lives in `src/products-data.js`.
4. Product images are in `assets/products/`.

## Customization notes
- Replace the temporary email wherever it appears.
- Update prices via the Admin page (`admin.html`) or edit `products-data.js`.
- Colors can be adjusted in the `:root` variables at the top of `src/styles.css`.

Built from the Zeemax template with improved branding, contact details, About/Contact content and minor design refinements.
